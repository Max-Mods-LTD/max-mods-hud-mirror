MAX MODS iDrive Apps — HUD Mirror 0.7.0

Update both apps. This release uses BMW's actual native menus and buttons,
adds recovery from failed page changes and improves frame-copy/rate handling.
The new UI and car display frame rate still need a physical test.

1. Car Store > Settings > Check now. Update Max Mods HUD Mirror to 0.7.0.
   GPU Video 0.1.0 remains a dependency; Max Mods Connect is no longer needed.
2. Install downloads/Max_Mods_HUD_Mirror_Android_v0.7.0.apk over the phone app.
   Stop the old sharing session. The APK uses the existing update certificate.
3. Park in P. Keep your working Bluetooth / Android Auto sound connection.
4. Car or phone > Connection guide, explains:
   iDrive COM / Communication > Mobile devices > right > Settings > Wi-Fi On.
   New device > Internet, apps shows the BMW network/password if equipped.
   Some cars show these under Mobile devices > Settings; labels vary.
5. Samsung Settings > Connections > Wi-Fi > join the BMW network.
   Choose Stay connected if it has no Internet. If Android Auto already has
   a working BMW Wi-Fi connection, keep it. Do not use garage Wi-Fi instead.
6. Sound: enable BMW Bluetooth Media audio, then MEDIA / Radio in the car,
   or use the existing Android Auto sound route. Wi-Fi carries the picture.
7. Phone > Start sharing > approve the entire screen.
   Car > Pair phone > enter the phone address/code exactly, with the slash.
   This is not the BMW Wi-Fi password. QR scanning has been removed.
8. Later sessions: start sharing on the linked phone; no second Start needed.
   Android capture consent still applies. A changed phone IP needs pairing.
9. If sound slows video: phone > Display > Sound coexistence > Audio priority.
   Auto also adapts hardware bitrate to audio and measured congestion. A
   factory 5 GHz option may help if your BMW offers it; the app does not
   change radio channels or audio routes. Local Wi-Fi and Internet data for
   online videos are separate connections/services.
10. Car Display settings > Destination: HUD / instrument cluster / iDrive screen.
    Only one runs at once. Picture size chooses Compact / Full; video options have their own page.
11. Keep mirroring on other pages: On lets HUD/cluster continue while you use
    Android Auto on the main screen. iDrive video uses this app's own page.
12. Phone > Display > video quality: Sharp 30 / Smooth 60 fps target.
    Stop sharing before changing it. Optional Display60 requests the shared
    renderer's 60 fps clock; install with other display apps stopped.
13. Automatic GPU uses a separate instance of an already-installed compatible
    Waze decoder. Missing/failed hardware falls back to JPEG. It does not
    install Waze or change its firmware/Android Auto patches.
14. Force close exits this app and its output. Reopen to reconnect.
    Car > Connection diagnostics shows phone capture/sent and car received fps,
    decoder, traffic, signal ages and last issue. What is new lists changes.
15. The car menus use BMW controls, fonts, layout and red selection highlight.
    For iDrive video, BMW Back or tapping the picture returns to settings.
    View iDrive picture reopens it. HUD/cluster sessions keep native menus
    available without starting a custom menu renderer.

A 60 Hz clock is not a guarantee of 60 fps. Test actual picture quality,
frame rate, phone edges and BMW speed/sign/gauge visibility. Park-only.
If Automatic GPU fails, choose JPEG compatibility. Use Forget linked car
on the phone to reset its saved reconnect credential.
